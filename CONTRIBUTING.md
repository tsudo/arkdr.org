# Contributing

Fork or download the code for your own use — that's fine.

This repo isn't currently accepting pull requests; it's maintained for one organization's specific volunteer/field operations, and content changes go through that organization directly rather than GitHub.

## Suggestions

Spotted a bug, a broken link, or an accessibility issue? Open an [issue](https://github.com/tsudo/arkdr.org/issues) — it'll get read.
